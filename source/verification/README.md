# Blind re-read

250 cells were drawn at random (seed 1931; 160 with values ≥ 10,000 and 90 smaller) from the
transcription. A separate reader, who was not shown the transcribed values, read them from the page
images (`blind_sample.json` → `blind_readings.json`).

Result: 247 of 250 agreed. On re-examining the scan, the 3 disagreements were errors by the blind reader:
- leaf 500, col 742, row 27 and col 744, row 32: the reader was one row off in a block whose figures
  drift against the row labels. The transcription agrees with the sums of the member languages
  (e.g. Hyderabad's Inner Sub-Branch equals Western Hindi + Rajasthani + Gujarati + Bhili + Panjabi).
- leaf 506, col 823, Provinces: 34,731, not 34,781. India 34,780 − States 49 = 34,731, and
  118,423 = 83,692 + 34,731.
